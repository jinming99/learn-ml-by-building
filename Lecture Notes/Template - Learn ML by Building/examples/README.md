# Native-LaTeX figure pattern library

These source examples preserve the figure language used in the polished Lecture 2 notes. They are not included by `main.tex`; copy and adapt the smallest relevant pattern into `figures/`.

- `knn-neighborhood.tex` - annotated scatterplot and neighborhood
- `k-behavior.tex` - multi-panel conceptual comparison
- `distance-geometries.tex` - metric contours
- `cosine-vectors.tex` - labeled vector geometry and angle
- `rank-matrix.tex` - ranked matrix or heatmap
- `system-pipeline.tex` - process diagram with feedback loop
- `compatibility-penalties.tex` - PGFPlots curve comparison

Replace lecture-specific labels and data. Preserve the shared palette, restrained line weights, caption style, and generous spacing around legends and annotations.

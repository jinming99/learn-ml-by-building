# Figure rules

Figures included in a lecture belong in this folder and must be written in TikZ or PGFPlots.

- Reuse the palette and styles in `lecture-notes.sty`.
- Keep one source file per figure.
- Include figures inside `widepar`, center them, and use `\FigureCaption`.
- Leave visible space between titles, subtitles, legends, annotations, and plotted marks.
- State whether values are observed, computed from current data, synthetic, or conceptual.
- Do not paste notebook screenshots or rasterized charts into the final notes.

See `../examples/figures/` for the complete pattern library taken from the polished Lecture 2 source.
